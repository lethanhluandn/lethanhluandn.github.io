# lethanhluandn.github.io

Personal portfolio website for **Le Thanh Luan**.

## Overview

This repository hosts a lightweight, static GitHub Pages portfolio built with plain HTML, CSS, and JavaScript.

## Local preview

Because this is a static site, you can open `index.html` directly in a browser, or run a simple local server from the repository root:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deployment

The site is intended for GitHub Pages and works from the repository root with relative asset paths.
